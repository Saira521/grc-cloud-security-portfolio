# GRC & Cloud Security Portfolio

This repository contains hands-on Governance, Risk & Compliance projects built in fictional environments to demonstrate practical capability in security governance, cloud risk, audit readiness, control mapping, evidence validation, and GRC-as-Code.

> **Portfolio disclaimer:** All organizations, systems, risks, evidence, findings, and metrics in this repository are fictional and created for learning and demonstration purposes. No confidential employer, client, or third-party information is included.

## Projects

### 01 — AWS + ISO 27001 Audit Readiness Lab
A fictional SaaS company hosted on AWS. The project demonstrates:

- scope definition and interested parties
- AWS/cloud asset inventory
- information classification
- risk methodology and risk register
- unified control library
- control-to-framework mapping
- evidence register and control testing
- design vs. operating effectiveness
- findings and corrective actions
- GRC-as-Code validation with Python and GitHub Actions

**Status:** In progress — started October 2026.

## Portfolio principles

1. Show operating evidence, not just policy documents.
2. Separate control design, implementation, and operating effectiveness.
3. Keep inherent and residual risk distinct.
4. Use structured, machine-readable controls where possible.
5. Never publish real company data, credentials, audit reports, or screenshots.
6. Do not reproduce copyrighted ISO standard text; use references/mappings only.
